# Article Screenshots

Add support article screenshots in this folder and reference them from
`src/pages/SupportPage/SupportContent.ts`.

Use public paths like:

```text
/assets/images/article_screenshots/properties-overview.png
```

Recommended naming:

```text
properties-overview.png
tasks-property-context.png
appliance-profile.png
document-review-summary.png
maintley-intelligence-card.png
maintenance-history-entry.png
contractor-profile-links.png
dashboard-focus-controls.png
```
